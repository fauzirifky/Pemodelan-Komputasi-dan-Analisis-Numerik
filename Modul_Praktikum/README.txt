PAKET SUMBER MODUL PRAKTIKUM MA25-31017

Isi:
- latex/modul.tex       : sumber modul praktikum
- latex/slides.tex      : sumber slide praktikum
- latex/enacom.cls      : kelas Enacom yang telah disesuaikan ke aksen warna ITERA
- latex/itera.png/pdf   : logo/motif ITERA yang diberikan pada percakapan
- matlab/*.m            : driver dan fungsi MATLAB untuk 10 praktikum

Catatan kompilasi:
1. Salin berkas di folder latex ke folder template Enacom asli yang Anda miliki.
2. Template Enacom asli memuat resource font sendiri. Resource font tidak disertakan di paket ini.
3. Jalankan pdflatex modul.tex dua kali untuk modul.
4. Jalankan pdflatex slides.tex dua kali untuk slide.
5. Folder matlab harus berada satu tingkat di atas folder latex, atau sesuaikan path ../matlab pada modul.tex.

Struktur praktikum telah diselaraskan dengan SAP Ganjil 2026/2027 dan CPMK/indikator operasional yang tersedia pada SAP.
