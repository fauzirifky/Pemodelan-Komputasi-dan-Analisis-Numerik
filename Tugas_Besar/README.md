## Pemilihan topik

Google Sheet pemilihan: https://docs.google.com/spreadsheets/d/1Z7TFpH8m0AEoP25FIAwMUMywgLYDUVBBlKkQOVzgSJI/edit

Aturan utama:

1. Satu masalah maksimal satu kelompok di RA dan satu kelompok di RB.
2. Jika masalah yang sama dipilih oleh RA dan RB, modelnya harus berbeda.
3. Pasangan **masalah + model** tidak boleh sama pada dua kelompok.
4. Model boleh digunakan pada problem berbeda bila secara ilmiah relevan.
